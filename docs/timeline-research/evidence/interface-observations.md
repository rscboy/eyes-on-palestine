# Representative interface observations

Reviewed on October 3, 2026. These are limited observations, not accessibility certifications or comprehensive usability tests.

## PalQuest
Opened the homepage, selected Overall Chronology, read the accessibility tree and inspected a desktop screenshot. A left date/period rail, central event spine with cards, and right period context pane preserve chronology and interpretation together. A separate grid/list route is available. The very long historical range uses changing label granularity. Some controls appeared as icon glyphs in the accessibility tree; Echoes of Gaza should use explicit names instead. No mobile or full keyboard audit was performed.

## New Museum Digital Archive
Opened the chronology, read dated entries and inspected the desktop screenshot. Decade links, record types and source-linked exhibition/publication/people records support discovery. The large photographic introduction precedes the chronological material. For Echoes of Gaza, give the working chronology greater initial visibility and keep contextual introductory material concise. No filtering or full keyboard audit was performed.

## MSF Gaza, inside the war
Opened the live site, inspected the introduction, selected Enter, inspected the event interface and selected the healthcare theme. The resulting page exposed corresponding healthcare event links. Desktop screenshot showed month rows, colored event markers, thematic and location filters, an overview rail and alternate view icons. The introduction explicitly bounds the compilation period. Some controls and event links had no names in the returned DOM snapshot; this observation motivates explicit naming and a fully readable equivalent list, but is not a complete accessibility judgment. No mobile, screen-reader or comprehensive keyboard audit was performed.

## 9/11 Memorial Timeline
Read the live About page through the browser. The page explicitly warns of graphic images and sensitive content and names the producing institution. The main chronology was not tested in the browser. Only those documented features support recommendations.
